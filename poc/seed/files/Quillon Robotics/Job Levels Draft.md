# Quillon Robotics: Job Levels Draft

Draft framework for discussion with Renata Solis.

| Level | Title (engineering) | Scope |
|---|---|---|
| E1 | Associate Engineer | Learns the codebase; works on well-defined tasks |
| E2 | Engineer | Owns features end to end with light guidance |
| E3 | Senior Engineer | Leads projects; mentors E1 and E2 |
| E4 | Staff Engineer | Sets technical direction across teams |
| E5 | Principal Engineer | Company-wide technical leadership |
